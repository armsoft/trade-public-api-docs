# C# Report Examples

🔗 [Online documentation](https://online.armsoft.am/trade7/restapi_reports.htm)

This folder contains C# client wrappers and example code for the API reports endpoints.

## Examples

- `partnersbalances.cs` - POST `/reports/partnersbalances`
- `partnersbalances-nextpage.cs` - POST `/reports/partnersbalances/nextpage`
- `productsbalances.cs` - POST `/reports/productsbalances`
- `productsbalances-nextpage.cs` - POST `/reports/productsbalances/nextpage`
- `productsbalances-short.cs` - POST `/reports/productsbalances/short`
- `productsbalances-short-nextpage.cs` - POST `/reports/productsbalances/short/nextpage`
- `pricelist.cs` - POST `/reports/pricelist`
- `pricelist-nextpage.cs` - POST `/reports/pricelist/nextpage`
- `salesanalysis.cs` - POST `/reports/salesanalysis`
- `salesanalysis-nextpage.cs` - POST `/reports/salesanalysis/nextpage`
- `bonusbalances.cs` - POST `/reports/bonusbalances`
- `bonusbalances-nextpage.cs` - POST `/reports/bonusbalances/nextpage`
