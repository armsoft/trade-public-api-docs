# C# Journal Examples

🔗 [Online documentation](https://online.armsoft.am/trade7/restapi_journals.htm)

This folder contains C# client wrappers and example code for the API journals endpoints.

## Examples

- `list-alldocuments.cs` - POST `/journals/alldocuments`
- `list-alldocuments-nextpage.cs` - POST `/journals/alldocuments/nextpage`
- `list-ecrchecks.cs` - POST `/journals/ecrchecks`
- `list-ecrchecks-nextpage.cs` - POST `/journals/ecrchecks/nextpage`
