# Products - Delete

## Description

Deletes a product by code.

## Endpoint

- **Base URL:** `https://api.armsoft.am/trade`
- **Method:** `DELETE`
- **Route:** `/v1/directories/products/{code}`
- **Authorization:** API key in header `apiKey`

## Path parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| code | string | Yes | Product code |

## Successful response

- **Status:** `200 OK`
